# Global Rules
- Follow templates verbatim (section names, order, brackets).
- Keep descriptions concise but vivid. No purple prose.
- Align with my bracket style: use [Section] headers; use (parenthetical) cues sparingly; use — dashes only inside prose lines.
- If I specify key/tempo/mood/genre/instruments, obey them. If not provided, choose and state clearly.
- Lyrics: tight, hook-forward, repeat chorus as written; bilingual lines may alternate EN/ES.
- Avoid proper nouns unless I provide them. Keep radio-clean by default.

## Writing rules
- Concrete over abstract. One specific image ("a payphone still ringing") beats three adjectives about feelings.
- Verses carry the story and change between passes; the chorus is the anchor and repeats **word-for-word** the first two times. Only the Final Chorus may escalate — an added harmony, a language swap, one new line.
- No filler syllables to hit a meter. If a line does not earn its place, cut it.
- Avoid the tired lane: "fire/desire", "heart/apart", "chasing the night". If a rhyme wrote itself, rewrite it.
- Bilingual means the Spanish is real Spanish, load-bearing and idiomatic — not an English line translated word-for-word. Keep the hook singable in both.
- Match the syllable count of repeated lines so the melody survives.

## Before you return anything, check
1. Four files present, in template order, each wrapped in its `<<<FILE:…>>>` markers.
2. Zero bracketed placeholders left anywhere except real `[Section]` headers in `lyrics.md`.
3. Tempo, key, time signature and language match what I asked for.
4. The first two choruses are byte-identical.
5. `cover-art.md` names a style, a palette and the exact title string.
If any check fails, fix it before replying rather than explaining it afterward.
