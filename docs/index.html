Wire up your Gem

        

          
    
            
  1. Create the Gem
              In Gemini, open Gems → New Gem and name it something like Song Architect.
    2. 
            
  2. Paste the instructions
              Copy the bundle on the right into the Gem's Instructions box. That's
              .gem/role.md + .gem/rules.md + .gem/tasks/song.md, concatenated.
    3. 
            
  3. Attach the house references
              Upload /templates and a couple of /examples packs as knowledge files,
              or paste them in the first message. The Gem imitates what it can see.
    4. 
            
  4. Compose and send
              Build a prompt on the Compose tab, hit Copy, send it.
    5. 
            
  5. Bring the reply back
              Paste the response into Decode to check it against the
              templates, then save the good ones into examples/.
    6. 
          


          
Why the loop matters

          

            The Gem has no memory of what "good" looks like beyond what you show it. Every pack you save
            into examples/ tightens the house style, so round five is noticeably better than
            round one. Decode → export → commit is the whole flywheel.


          
Iterating on one file

          

            Deselect files in Output & constraints and the prompt switches to iteration
            mode — it asks for only the files you left checked and tells the Gem to hold everything else
            fixed. That is how you fix a weak bridge without losing a good hook.
